GUÍA GRATUITA

Revisar enlaces sospechosos gratis

Si recibes un enlace extraño por SMS, correo, redes sociales o mensajería, una herramienta de reputación puede ayudarte a obtener una señal adicional antes de interactuar con él. Esto no garantiza que una URL sea segura, pero puede revelar detecciones conocidas.

No abras el enlace únicamente para comprobar qué contiene. Copia la URL sin visitarla y analízala desde un servicio de confianza.

Herramienta recomendada

Uso básico gratuito

VirusTotal

Permite consultar URLs, dominios y archivos con múltiples motores y fuentes de seguridad.

Señales de alerta comunes

  • Dominios que imitan el nombre de un banco, paquetería o tienda conocida.
  • Mensajes que crean urgencia para iniciar sesión o realizar un pago.
  • URLs acortadas cuyo destino no puedes identificar.
  • Solicitudes de códigos, contraseñas o datos bancarios.
  • Archivos inesperados adjuntos al mensaje.

Qué hacer si tienes dudas

En lugar de usar el enlace recibido, entra manualmente al sitio oficial o a la aplicación del servicio. Si el mensaje afirma que existe un problema con tu cuenta, compruébalo directamente desde el canal oficial. Cuando se trate de información financiera o corporativa sensible, una revisión profesional puede ser más apropiada.

Importante

Los analizadores de reputación no detectan necesariamente amenazas nuevas o ataques dirigidos. Un resultado sin detecciones no debe interpretarse como una garantía absoluta de seguridad.
